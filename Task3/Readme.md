# Реестр программных и аппаратных средств для защиты 
|Данные|В чём необходимость защиты|Инструменты защиты|
|-------|--------------|--------------|
|Персональные данные пациентов (PII): ФИО, паспорт, ИНН, СНИЛС, контактные данные|Регламентируется 152-ФЗ|Шифрование данных и хранилищ. Мониторинг доступа (SIEM). Аудит чтения и изменения. Спецтэг для таких данных в BigID и KeyCloask (:pii). Разграничение доступа по матрице RBAC|
|Медицинские данные внутри контура Medicamente (PHI): карточка пациента, анализы, назначенное лечение|Регламентируется нормативными актами: ФЗ №323 "Об основах охраны здоровья" (ст. 22, 79), ФЗ №152, Приказами Минздрава: Приказ №29н (2021) и тд.|Шифрование данных и хранилищ. Мониторинг доступа (SIEM). Аудит чтения и изменения. Спецтэг для таких данных в BigID и KeyCloask (:phi). Разграничение доступа по матрице RBAC. Простая электронная подпись или ЭЦП для врачей.|
|Медицинские данные поступающие из внешних источников: результаты анализов из лабораторий|Регламентируется нормативными актами: ФЗ №323 "Об основах охраны здоровья" (ст. 22, 79), ФЗ №152, Приказами Минздрава: Приказ №29н (2021) и тд.|Зашифрованные каналы связи. Например Https с TLS версией ни ниже 1.2. Межсетевые экраны\прокси. KeyCloak аутентификация. Мониторинг, DLP и SIEM.|
|Аналитическая информация: любые данные внутри компании, включая данные о клиентах, мед. данные и данные сотрудников|Могут содержать персональную информацию, медицинскую информацию, которые надо хранить согласно требованиям регулятора. Например 152-ФЗ. Также могут содержать коммерческую тайну.|В первую очередь обезличивание персональных и медицинских данных. Проверка качества обезличивания с помощью BigID. Авторизация к данным посредством KeyCloask и ролевой модели RBAC. SIEM для мониторинга|
|Корпоративные данные: данные о сотрудниках, зарплатах, закупках|Коммерческая тайна|Разграничение доступа по матрице RBAC. SIEM для мониторинга|
|Служебная информация: логи, конфиги, отчеты, бэкапы|Могут содержать коммерческую тайну|Шифрование бэкапов. Изоляция тестовых и продуктивных сред, например, ДМЗ. RBAC, DLP и SIEM.|
